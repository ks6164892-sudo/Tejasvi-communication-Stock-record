TEJASVI COMMUNICATION - MOBILE STOCK MANAGER

Open index.html in a modern browser (Chrome recommended).

Demo admin credentials:
Username: admin
Password: tejasvi123

Features in this prototype:
- Stock dashboard with variant count, unit count, low/out stock count, retail inventory value
- Inventory search and brand/stock filters
- Admin add/edit/delete stock
- Fields: brand, model, colour, RAM, ROM/storage, selling price, quantity, cost price, notes
- Saves to local browser storage

IMPORTANT:
This version stores stock in local browser storage. It is a working single-browser prototype, not a cloud real-time multi-user system. For shared live updates across phones/PCs, connect a Firebase/Supabase database and secure admin authentication before deploying publicly. Demo password is not secure for production.
